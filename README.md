# Herd & Homeland

Website for the research project *Herd & Homeland: Animals, Ethics and Hard Choices in Wartime Sweden*
(Formas, 2026–2028, Linnaeus University & BTH). Planned domain: animalsinwar.com.

Static site (HTML/CSS/JS, no build step), bilingual EN/SV via `data-en` / `data-sv` attributes.

| File | Purpose |
|------|---------|
| `index.html` | Home, About, Research (incl. how to contribute), Team |
| `css/style.css`, `js/main.js` | Styles, language switch, menu |
| `images/` | Team photos, favicon, hero image (`hero.jpg`), share image (`og-image.jpg`) |
